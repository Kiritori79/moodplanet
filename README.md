# 情绪星球 MoodPlanet

自助式情绪记录与疏解工具的官网首页。

## 功能理念

围绕「记录 → 理解 → 疏解 → 成长」四个环节：

- **记录**：30 秒情绪打卡（强度滑动 + 标签 + 语音转文字）、漏记补记、情绪日历热力图
- **理解**：AI 将情绪数据与睡眠、天气、日程、社交交叉分析，输出触发因素排行与每周情绪周报
- **疏解**：按当下状态推荐冥想 / 呼吸 / 疗愈音乐 / 微运动，并做疏解前后对比；焦虑突发时提供情绪 SOS 急救模式
- **信任**：端到端加密、多端同步、一键导出或彻底删除

## 页面结构

导航 → Hero → 如何运作 → 核心功能 → 更多功能 → 常见问题 → 终极 CTA → 页脚

## 技术

纯静态单页（HTML + CSS + 原生 JS），零依赖、零构建，可直接托管在 GitHub Pages 等静态服务上。

## 本地预览

```bash
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000
```
